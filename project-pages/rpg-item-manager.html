RPG Item Manager - Unity Editor Plugin
Role: Solo Developer
Team Size: Solo | Keywords: Unity (C#), UI Toolkit, JSON
Overview
The RPG Item Manager is a custom Unity Editor plugin designed to streamline the management of RPG item data within the Editor environment. Built using Unity’s UI Toolkit, it provides developers with a structured, visual interface for creating, editing, and organising items such as weapons, armour, and NPCs - all directly inside the Unity Editor.
This tool enhances productivity by eliminating the need to manually manage complex data structures or navigate through multiple ScriptableObject assets, instead offering a clear, interactive overview of all item data through a single custom window.
View project on Github
My Contributions
  • Developed a custom Editor window using Unity’s UI Toolkit with SplitView, ListView, and Foldout components for intuitive data navigation.
  • Implemented dynamic foldout creation using a dictionary of UI templates to automatically generate property fields based on item type.
  • Designed a flexible layout system that organises item details across dual panes (left/right) for improved readability and workflow.
  • Added interactive controls with PopupFields and Buttons for creating, modifying, and deleting item entries within the Editor.
  • Built a JSON serialization system for saving and loading item data, with automatic folder organisation by item type (e.g., Weapons, Armour, NPCs).
  • Created a robust ItemSerialization class to handle disk operations, converting item objects to and from JSON using Unity’s JsonUtility.
Tools & Technologies
Unity (C#), UI Toolkit, JSON Serialization, Editor Scripting
Focus
This project focused on extending the Unity Editor to support data-driven game design, improving workflow efficiency and maintainability for large-scale RPG systems. It strengthened my skills in Editor UI development, data serialization, and tool design for production pipelines.
