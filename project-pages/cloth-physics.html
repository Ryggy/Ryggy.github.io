Cloth Physics Simulation — Verlet Integration
Role: Programmer
Team Size: 2 | Keywords: Unity (C#),Verlet Integration, Cloth Physics, Rope Physics
Overview
This interactive 2D cloth and rope physics simulation demonstrates the use of Verlet integration for stable, realistic motion updates.
Inspired by Sebastian Lague’s physics tutorials , the project focuses on the fundamentals of constraint-based physics, allowing users to create, manipulate, and destroy rope and cloth structures in real time. The simulation serves as both a learning tool and a technical showcase for numerical integration, constraint solving, and interactive physics systems in Unity.
View project on Github
General Controls
  • Spacebar: Pause/Unpause the simulation.
  • Right Click: Destroy connections between nodes.
Rope Simulation
Placing nodes works best while paused for rope simulation.
  • Left Click: Spawn nodes to create a rope structure.
  • Shift + Left Click: Spawn pinned nodes that remain fixed in position.
  • Left Click + Drag on Selected Node: Create connections between nodes to form the rope.
Cloth Simulation
  • Left Click + Drag: Create cloth by dragging from the start point to the end point.
My Contributions
  • Implemented Verlet integration for position updates, ensuring smooth, stable simulation without relying on Unity’s built-in physics engine.
  • Built a constraint system connecting node pairs, maintaining distance and structure stability for both rope and cloth configurations.
  • Created interactive tools for users to generate, connect, and sever nodes dynamically during runtime.
  • Added input controls for pausing, pinning, cutting, and spawning nodes, enhancing interactivity.
Tools & Technologies
Unity (C#), Verlet Integration, Constraint Solving, Custom Physics Systems
Focus
This project explored numerical integration and physics-based simulation design, deepening my understanding of motion constraints, stability, and real-time interactivity. It provided hands-on experience in implementing custom physics engines within Unity and optimising for responsiveness, accuracy, and user control.
