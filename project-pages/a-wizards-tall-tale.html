A Wizard’s Tall Tale - Vertical Platformer
Role: Programmer / Level Designer
Team Size: 3 | Keywords: Unity (C#) | Platform: PC
Overview
A Wizard’s Tall Tale is a vertical platformer that follows a novice wizard climbing a mysterious tower with only one spell to rely on. Players must use timing, precision, and creativity to master their limited abilities - leaping, dashing, and double-jumping their way through a labyrinth of mystical hazards, ancient ruins, and strange creatures.
Check it out on Itch.io! View project on Gitlab
My Contributions
  • Character Controller: Developed a responsive 2D controller supporting jumping, dashing, and spell-based mobility.
  • Input System: Implemented custom player input handling for precise, timing-sensitive controls.
  • Level Design: Created the first level layout, balancing platform placement, enemy encounters, and pacing for vertical traversal.
  • Scoring System: Designed and integrated a high-score framework to track performance and encourage replayability.
Tools & Technologies
Unity (C#), Tilemap Editor, 2D Physics, GitHub
Focus
This project emphasised responsive controls, tight platforming design, and the challenge of building a complete gameplay loop around a limited ability set. It strengthened my understanding of 2D movement systems, level pacing, and player feedback.
