Grass Geometry Shader - Procedural Foliage Rendering
Role: Solo Developer
Team Size: Solo | Keywords: Unity (C#, HLSL, URP)
Overview
This project is my first dive into shader development, exploring how to create dynamic, efficient, and visually engaging grass rendering using a geometry shader.
The shader procedurally generates grass blades from geometry billboards, adds wind animation for natural movement, and introduces randomisation and customisable controls to achieve organic variation. Inspired by works from MinionsArt and AJTech2002 this shader provided a foundation in understanding vertex transformation, lighting models, and real-time GPU optimisation within Unity’s Universal Render Pipeline (URP).
View project on Github
My Contributions
  • Implemented a geometry-based grass rendering pipeline that builds grass blades procedurally using billboarded triangles.
  • Added wind distortion and sway simulation through vertex offset calculations for natural, reactive movement.
  • Introduced randomised variation in height, colour, and rotation to avoid visual repetition.
  • Exposed custom parameters in the Unity Inspector, enabling adjustments for density, height, wind strength, and colour blending.
  • Experimented with performance optimisation using billboard rendering, LOD transitions, and simple culling to maintain high frame rates.
Tools & Technologies
Unity (URP), HLSL, Shader Graph, Geometry Shaders, GPU Optimisation, Level of Detail (LOD)
Focus
This project was a deep introduction to shader programming and the underlying mathematics of GPU rendering. It helped me understand how geometry shaders can create efficient natural environments and how small visual details like motion, variation, and lighting can transform static scenes into immersive worlds.
