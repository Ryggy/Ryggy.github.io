LevelCraft — Level Design Analysis Toolkit
Role: Solo Developer
Team Size: Solo | Keywords: Unity (C#), Editor Scripting, UI Toolkit, Data Visualisation
Overview
LevelCraft is a comprehensive Unity package designed for beginner game designers and educators to visualise, analyse, and refine level design directly within the Unity Editor.
LevelCraft acts as both a teaching aid and a professional workflow enhancer - helping users understand spatial relationships, player behaviour, and gameplay balance through accessible, data-driven tools.
The toolkit consists of a heatmap generator, placement tool, field of view tool, measurement tool and a level statistics tool.

My Contributions
  • Designed and implemented multiple editor tools for analysing and visualising level structure, including heatmaps, measurement systems, and field of view visualisers.

Focus
The goal of LevelCraft was to create accessible yet technically robust editor tools that support learning through design practice. The project strengthened my understanding of data-driven level design, custom editor development, and tool usability.
