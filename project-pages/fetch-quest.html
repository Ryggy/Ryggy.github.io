Fetch Quest - Arcade Delivery Racing Game
Role: Programmer / Gameplay Designer
Team Size: 3 | Keywords: Unity (C#) | Platform: PC
Overview
Fetch Quest is a fast-paced arcade delivery game where players take on the role of an overly ambitious delivery van driver.
Set in a vibrant, top-down isometric city, players must navigate tight corners, dodge traffic, and deliver packages as efficiently as possible. The game rewards skill, speed, and precision, encouraging players to master routes and chase high scores through quick, replayable sessions.
Check it out on Itch.io! View project on Github
My Contributions
  • Core Gameplay Systems: Designed and implemented delivery mechanics, including package pickup, drop-off, and dynamic time scoring.
  • Scoring and Progression: Developed the point and combo systems.
  • Control Scheme: Created an accessible driving control system optimised for isometric camera movement.
  • User Interface: Designed and programmed UI elements for score tracking, time management, and mission feedback.
Tools & Technologies
Unity (C#), Github, Visual Studio
Focus
This project explored how simple mechanics and tight control design can create engaging gameplay loops. It strengthened my understanding of moment-to-moment player feedback, system balancing, and UI integration
